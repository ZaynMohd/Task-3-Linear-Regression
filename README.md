# Task 3 - Linear Regression

## Objective

The objective of this task is to implement and understand Simple and Multiple Linear Regression for house price prediction.

## Tools Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset

A House Price Prediction dataset was used for this task.

## Steps Performed

1. Imported and explored the dataset.
2. Preprocessed categorical features using encoding.
3. Split the dataset into training and testing sets.
4. Implemented Simple Linear Regression using area as the predictor.
5. Implemented Multiple Linear Regression using multiple house features.
6. Evaluated both models using MAE, MSE and R² score.
7. Plotted the regression line for Simple Linear Regression.
8. Created an Actual vs Predicted plot for Multiple Linear Regression.
9. Interpreted the model coefficients.

## Model Comparison

Simple Linear Regression uses only the area feature to predict house price.

Multiple Linear Regression uses multiple features such as area, bedrooms, bathrooms, stories, parking and other encoded features.

The Multiple Linear Regression model achieved a higher R² score than the Simple Linear Regression model, showing that multiple features provide better predictive information.

## Conclusion

Linear Regression was successfully implemented for house price prediction. The models were evaluated using MAE, MSE and R² score, and the coefficients were interpreted to understand the contribution of different features.
